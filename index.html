Page Viewer — how to use

  • The sample page loads automatically (and comes back when you reload this tool). To inspect any other page, type its address in the URL bar and click Load page from URL — page scripts are always disabled in the preview.
  • The HTML tree shows the complete raw markup, pretty-printed and syntax-linted: opening and closing tags, attribute names, values, text and comments are colour-coded, and hovering any of them shows what kind of HTML syntax it is. Hovering a row outlines the element on the page; hovering the page highlights its row in the tree.
  • Click an element: it is outlined on the page, its MDN entry loads in the Reference panel, and it completes the matching objective in the quest tracker (top-right of the preview) — find all 28 RefG §4 items to complete the quest. Collapsing the tracker shows just the next three objectives; Reset Progress in the top bar clears it.
  • In the CSS panel, untick any rule — or a whole stylesheet — to see the page without it. The top section lists the rules that currently match the selected element, most specific first. Blue property names appear in the RefG §6 property list.
  • Character references (&amp; &lt; &gt; &quot;) are ticked when you select content that needed them.
  • Progress is saved in this browser until you press reset.

Privacy: pages that cannot be read directly are fetched through a public CORS proxy service, so the URLs you inspect are shared with it — do not inspect pages that need a login. The preview always disables page JavaScript.
